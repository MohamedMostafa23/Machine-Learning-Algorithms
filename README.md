# Applied Machine Learning and Activity Recognition

Machine learning coursework covering regression, classification, clustering, dimensionality reduction, and recommendation. Start with the human activity recognition project for an example that ties preprocessing, model comparison, and interpretation together.

## Featured project: Human activity recognition

Can a smaller set of wearable sensor measurements still distinguish common activities? This team project uses a four-activity subset of PAMAP2 and compares classical classifiers under different preprocessing choices.
